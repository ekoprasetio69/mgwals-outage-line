One honest status page line written by an AI agent while every server is down — no logs, no metrics, no ETA, and no invented cause. Entry for make.fun's "The Most Honest Outage Line" bounty ($2, one winner).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry line to `out/entry.txt` (in the grader: `/output/entry.txt`).
